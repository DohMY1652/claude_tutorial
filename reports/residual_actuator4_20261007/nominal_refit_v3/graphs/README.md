# 실측 · 공칭 · 전체 모델 비교 그래프

검정 실선은 실측, 주황 점선은 최신 왕복 중심 공칭,
파랑 실선은 그 공칭에 새 residual을 더한 전체 모델이다.
이전 모델이 아니라 `nominal_refit_v3` 후보를 비교한다.

- `01_all_runs_overlay.png`: 전체 실행을 누적 시간으로 이어 본 각도/오차.
- `02_profiles_overview.png`: 12개 실행을 개별 패널로 비교.
- `03_...png`–`14_...png`: 실행별 확대 그림. 각도, 예측 오차, 측정 압력 포함.
- `comparison_all_pages.pdf`: 위 그림 14장을 모두 수록한 PDF.

원본은 상위 폴더의 `all_runs.csv` 45,474행이다. 예측을 다시 피팅하거나
측정값/예측값을 평활화·이동·보정하지 않고 그대로 그렸다.
유효 블록/실행 경계를 가로질러 선을 잇지 않는다. 확대 그림의 점선은
블록별 초기 상태 재설정을 표시한다. 전체 그림의 시간은 그래프용 누적
시간이며 실행 사이 실제 경과 시간이 아니다.

전체 그림의 RMSE는 학습·개발·기존 진단 표본을 합친 표본 가중 지표다.
독립 검증 오차가 아니다. 구간별 결과와 모델 한계는 상위 `REPORT.md` 참조.

재생성 (오프라인 CSV 읽기 및 그림 저장만 수행):

```sh
PYTHONNOUSERSITE=1 MPLCONFIGDIR=/tmp/ph_mpl python3 -m ph_model.plot_predictions
```
