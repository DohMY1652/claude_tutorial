# 중력·릴 반경 재식별 및 passive residual 재학습 (2026-10-07)

최종 감사·보고 완료: 2026-10-08.

**결론: 개발/기존 진단 랜덤 궤적은 개선됐지만, 공칭 단독과 일부 정형
시험은 악화됐다. 전체 모델 피팅 성공으로 판정하지 않고 별도 비교 후보로 보존한다.**

## 범위와 판정 기준

액추에이터 4, 장착 2의 기존 측정 챔버 압력으로 오프라인 계산했다.
실기 명령을 실행하지 않았고 압력 제어 설정, 엔코더 보정, 원본 로그,
`main.tex`, 기존 모델, 기존 CSV 및 USB 파일을 변경하지 않았다.

질량과 부하 거리를 별개의 실측값으로 식별하지 않고 중력 계수 `Mg`를 탐색했다.
같은 각도의 상승/하강 정착점을 짝지어 왕복 중심과 반폭을 분리한 뒤,
릴 반경 민감도와 공칭 재피팅, 새 residual 학습을 차례로 수행했다.
오차 감소와 실제 기계 파라미터 식별은 별개의 판정이다.

## 1. 공칭 모델: 중력과 탄성의 구분이 충분하지 않다

학습 S2의 세 중심압 그룹과 S1a/S1b의 왕복 중첩 각도 영역에서만 보간했다.
총 75개 보간점은 독립 측정 75개를 뜻하지 않는다. 외삽하지 않았다.
왕복 평균의 압력 토크를 `Mg*sin(q)+k*q+c`에 맞추는 대칭 근사다.
실제 토크 센서 측정이나 이력 제거의 정확한 증명이 아니다.

반경 25 mm에서 얻은 중심 공칭은 다음과 같다.

| 파라미터 | 값 | 해석 |
| --- | ---: | --- |
| Mg | 2.71324 N·m | 중력과 탄성을 분리했다고 볼 수 없는 유효값 |
| k | 1.13174 N·m/rad | 2차 탄성 퍼텐셜 계수 |
| c | −0.831736 N·m | 탄성 퍼텐셜의 선형 항 |
| x1 초기 길이 | 50 mm | 탐색 하한에 도달, 실측 길이 아님 |
| alpha | 0.461757 | 중심 특성 고정 후 자유 궤적으로 식별 |
| b | 0.605178 N·m·s/rad | 같은 조건의 점성 계수 |

J=0.045 kg·m², 반경 25 mm, 벨로우즈 지름 50 mm, 주름 기하,
epsilon=0.02 rad/s는 고정했다. 특히 J와 epsilon은 이번에 검증된 실측값이 아니다.
중심 힘 RMSE는 8.682 N이다.

개발 구간에서 기존 최선 공칭의 RMSE는 5.35489°, 새 중심 공칭은 6.75946°다.
**공칭만의 예측은 개선되지 않았다.** 중심 정특성을 맞추는 것이 동적 이력까지
맞추는 것은 아니다. 이 공칭은 residual 분해를 시험하는 대안으로만 사용했다.

Mg·탄성·마찰을 전체 궤적에 동시에 최적화하면 RMSE 5.13905°가 나오지만,
Mg가 탐색 하한 부근인 0.20072 N·m로 떨어지고 k가 3.64070으로 커진다.
설정상 2 kg, 0.15 m의 중력 계수 2.943 N·m와 크게 다른 이 결과를
실제 부하가 작다는 증거로 채택하지 않았다. 누락된 거동을 다른 항이
대신 설명하는 것일 수 있다. 설정값 자체도 독립 실측이 확인된 것은 아니다.

`selected_nominal.json`과 `nominal_selection.json`은 이 **수치상 최선 후보**를
기록한 파일명이다. 물리 파라미터로 채택했다는 뜻이 아니다.
실제 새 residual의 고정 공칭은 `residual/protocol.json`에 명시된
`fixed25_central_then_friction`이다.

### 조건부 중력·반경 민감도

25 mm에서 Mg를 고정하고 탄성만 다시 맞춘 중심 힘 오차:

| Mg [N·m] | 재피팅 k [N·m/rad] | 중심 힘 RMSE [N] |
| ---: | ---: | ---: |
| 0.5 | 2.809 | 8.890 |
| 1.0 | 2.430 | 8.807 |
| 2.0 | 1.672 | 8.704 |
| 2.943 | 0.958 | 8.684 |
| 4.0 | 0.157 | 8.753 |

Mg가 크게 달라도 탄성 항을 바꾸면 거의 같은 오차가 나온다.
이 표는 조건부 목적함수 탐색이며 신뢰구간이 아니다.
질량과 거리를 동시에 자유롭게 바꿔 실제 값을 알아냈다고 주장할 수 없다.
특히 더 유연한 탄성/NN 퍼텐셜까지 허용하면 중력 퍼텐셜의 변화분을
그 퍼텐셜이 상쇄할 수 있다. 관측 각도만으로 퍼텐셜의 각 성분에 고유한
물리적 의미를 부여하기 어렵다. J를 고정한 Mg 스캔은 조건부 민감도이며,
실제 질량을 바꿨을 때 관성까지 일관되게 바뀌는 실험을 대신하지 않는다.

| 릴 반경 [mm] | 중심 피팅 Mg [N·m] | 동시 피팅 Mg [N·m] | 동시 피팅 개발 RMSE [°] |
| ---: | ---: | ---: | ---: |
| 20.0 | 2.1944 | 0.2004 | 5.1495 |
| 22.5 | 2.4549 | 0.2005 | 5.1441 |
| 25.0 | 2.7132 | 0.2007 | 5.1399 |
| 27.5 | 2.9697 | 0.2009 | 5.1364 |
| 30.0 | 3.2244 | 0.2011 | 5.1337 |

반경 표의 RMSE는 50 ms midpoint 민감도 계산값이다.
20–30 mm 차이에도 오차 차이가 약 0.016°에 불과하고 Mg가 함께 변한다.
30 mm를 실제 릴 반경으로 채택하지 않고 25 mm를 유지했다.
반경을 바꾼 모든 후보에서 변위·토크·압력 출력 포트의 반경을 같이 바꿨다.
상세 수치는 `radius_profile.json`, `gravity_profile.json`, 그림은
`identifiability.png`에 있다.

## 2. Residual 재학습 방식

중심 공칭을 고정하고 새로운 float64 SiLU NN을 출력 0에서 시작했다.
식 오차 600스텝은 초기화로만 사용했다. 이후 두 양의 이력 초기값에서
전체 유효 학습 궤적의 자유 예측 오차를 최적화했다. 각 블록의 시작 각도와
속도만 관측값을 쓰고, 이후 실제 각도를 모델에 계속 주입하지 않았다.
이력 초기 상태는 각 블록에서 xi=q로 고정했다.

압력과 독립인 스칼라 퍼텐셜, 비음수 소산 및 수동 이력 요소만 사용했다.
자유 힘 NN, 압력 의존 저장 에너지, 자유 RNN, ReLU는 넣지 않았다.
유효면적 NN 보정은 이번에 추가하지 않았다.
공칭은 residual 학습 중 고정했다. 이력 rv=0.0001은 새 모델 기본값으로
고정했으며 이전 모델의 약 0.000001과 다르다. 따라서 개선을 Mg 변경
하나의 효과라고 해석할 수 없다.

학습 seed 0–2 및 기존 정형 프로파일, 개발 seed 3의 분리를 유지했다.
기존 v2도 개발 후보 비교에 포함했다. seed 4의 정상 prefix는 선택을 마친
뒤 진단에만 사용했다. 이미 여러 번 본 데이터이므로 블라인드 검증이 아니다.

선택된 새 후보는 `central_residual_start1`이다. 개발 RMSE는 독립 적응
적분기로 4.04638°이며 이전 v2의 4.64605°보다 약 12.9% 낮다.
개발 최대 절대 오차도 7.72484°에서 6.82152°로 줄었다.
하지만 추가 점성 혼합은 0, 추가 마찰 혼합은 약 1e-14이고,
이력 강성은 [0.0081407, 0.0759622] N·m/rad로 작아졌다.
개발 오차 개선이 이력 특성의 올바른 식별을 뜻하지 않는다.

S1a 그래프에서는 높은 각도의 상승 유지점과 하강 전환이 맞지 않으며,
일부 전환에서 예측이 실제보다 급하다. S4에서는 첫 유지점에 약 6°의
지속 오차가 남고, 거의 같은 압력에 대한 서로 다른 유지 각도가 충분히
재현되지 않는다. 이는 수동성 보장과 예측 정확도가 다른 요구라는
구체적인 사례다. 개발 최선 후보라는 의미로만 보존하고 기존 모델을
대체하거나 '모델 피팅 완료'로 선언하지 않는다.

## 남은 문제와 다음 판단

이전 S4 진단에서 거의 같은 측정 압력인데 접근 이력에 따라 유지 각도가
약 5.57° 달랐다. 정지 시 tanh 마찰이 0인 현재 무이력 공칭만으로는,
현재 단조 복원 특성에서 이 두 평형을 동시에 설명할 수 없다.
부하·거리·반경을 더 많이 풀어 주는 것만으로 이 문제가 해결되지 않는다.

추가 실기 시험에 앞서 실제 매단 질량, 회전축에서 질량 중심까지의 거리,
텐던이 실제 감기는 반경, 대기압의 챔버 길이를 확인하는 것이 유용하다.
별도 진자 시험으로 J를 확인하면 관성과 소산의 혼동도 줄일 수 있다.
이 보고는 해당 실기 작업을 실행하거나 안전성을 검증한 것이 아니다.
공칭 기하를 바꾸거나 추가 이력 모델을 쓰기 전에는 논문 식 및 물리
제약과 맞는지 별도로 확인해야 한다. 현재 데이터에는 독립적인 신규
검증 세션과 다른 액추에이터/장착 데이터가 없다.

## 재현

구현·절차는 `ph_model/NOMINAL_REFIT.md` 참조.
결과 생성은 `ph_model.refit_nominal`, `ph_model.retrain_physical_residual`,
검사는 `ph_model.audit_nominal_refit` 순서다. 모두 ROS 없는 오프라인 작업이다.

CSV `all_runs.csv`는 유효 구간을 10 Hz로 모아 `time_s`를 0.1초 간격으로
이어 붙인다. 이는 그래프용 누적 축이지 실험 사이의 실제 경과 시간이나
모델을 중단 없이 적분했다는 뜻이 아니다. `run_id`, `block_id`, `block_start`,
원래 실행 시간 `t_mono_s`를 함께 보존한다. 각도는 도, 압력은 kPa absolute다.

- `angle_actual_deg`: 유효 측정 각도(시간 격자에 재표본화).
- `angle_nominal_previous_deg`: 이전 최선 공칭.
- `angle_nominal_refit_deg`: 새 왕복 중심 공칭.
- `angle_residual_previous_deg`: 이전 v2 residual 포함 모델.
- `angle_residual_selected_deg`: 이번 개발 최선 residual 포함 모델.

무효 구간을 제외한 블록마다 시작 상태가 재설정된다. 그 경계의 그래프 연결을
실제 각도 점프나 모델의 자유 예측 결과로 해석하지 않는다. CSV의 공칭과
residual 예측에는 모두 같은 측정 압력 및 유효 시각을 사용했다.
