## 1. 무엇을 수정했는가

기존의 관측 속도 기반 식 오차 / 10초 창 출력층 피팅 대신,
10개 학습 프로파일의 **전체 유효 연속 구간 자유 예측 오차**를 최소화했다.
각 블록 시작 상태만 측정값으로 맞추고 이후 실측 각도를 주입하지 않는다.
이력 상태는 학습 때도 모델 속도로 적분하므로, 측정 미분 잡음이 `rho*abs(qdot)`에
계속 들어가는 기존 학습/자유 예측 차이를 제거했다. 원본과 SG 필터는 바꾸지 않았다.

수정한 변수는 퍼텐셜 NN 출력층 17개, 비음수 추가 마찰 계수 4개,
양의 이력 강성 2개와 속도 의존 이완 계수 2개다. 두 초기값을 시험했다.
첫 후보는 수렴 판정에 도달했고, 두 번째는 22회 함수 평가 한도에서 종료됐다.
이는 전역 최적화의 완료를 뜻하지 않는다.

고정한 항목:

- nominal의 J, 중력, 챔버 기하, 마찰 alpha/b/epsilon, 탄성 파라미터.
- NN 은닉 기저, 추가 점성 계수, 이력 정지 이완율 rv, 유효면적.
- 데이터 분할, 평가 시각·압력·각도, 블록 초기조건.

따라서 이번 시험은 **현재 공칭을 그대로 둔 residual 개선의 한계**를 보는 실험이다.
공칭 파라미터까지 올바르게 다시 식별했다고 해석하지 않는다.

## 2. 공칭 모델은 문제가 없는가? — 아니다

두 가지를 구분해야 한다.

**식·단위 구현:** 조사한 범위에서 압력 채널 순서/절대압→게이지압/Pa 변환,
deg→rad, 토크 부호, 중력 퍼텐셜 미분에 오류를 찾지 못했다.
코드는 `tau=r*(-A1*P1+A2*P2)`이고 중력은 `Mg*sin(q)`로 한 번만 반영한다.
면적 회귀값, 전력 항등식, 독립 적분 비교 테스트도 통과한다.
이는 실제 물리 파라미터가 맞다는 증명이 아니다.

**물리적 설명력·식별:** 현재 공칭은 정지 이력과 실측 탄성의 제약이 부족하다.
단순 구현 버그 하나를 고치면 해결되는 것으로 확인되지 않았다.

### 2.1 같은 압력에 서로 다른 정지 각도가 있다

S4 각 120초 유지 구간의 마지막 30초 평균을 원본에서 다시 계산했다.

| 목표 차압 | 아래에서 접근한 각도 | 위에서 접근한 각도 | 차이 |
| --- | ---: | ---: | ---: |
| 24 kPa | 27.6217° | 33.1870° | 5.5653° |
| 48 kPa | 41.7861° | 44.7775° | 2.9914° |
| 60 kPa | 45.4829° | 46.7527° | 1.2698° |

24 kPa 쌍의 실제 P+ 평균은 113.28344 / 113.28439 kPa,
P− 평균은 89.34041 / 89.34408 kPa다. 각도 표준편차는 각각 0.0128° / 0.0070°다.
압력 차이가 커서 각도가 달랐다고 설명하기 어렵다.

현재 nominal에서 정확히 정지하면 `tanh(0)=0`, `b*qdot=0`이므로
`V0'(q)=tau(q,P)`만 남는다. 현재 기하와 양의 이차 탄성으로는 운용 각도 범위에서
복원 강성이 양수여서 같은 압력의 정적 평형은 하나다.
이 구조로 위 두 각도를 모두 정지 평형으로 맞출 수 없다.

S2를 같은 각도에서 왕복 짝지은 탐색 진단에서도, 이차 탄성 nominal의 중심 토크
오차 RMS는 중심압 101.3/108/115 kPa에서 각각 0.292/0.226/0.167 N m였다.
따라서 정지 이력만 추가하면 공칭의 중심 특성까지 모두 해결된다고 볼 수 없다.
이 수치는 정착점 사이 선형 보간 및 왕복 대칭 근사를 쓰므로 정밀한 힘 식별값은 아니다.

그러므로 nominal의 성공 기준을 모든 이력 궤적 일치로 잡아 물리 값을 왜곡해서는 안 된다.
nominal은 중간 정특성·기본 토크 관계를, 이력 항은 접근 경로 차이를 맡도록 분리해야 한다.
이력 잔차가 필요하다는 사실과 nominal의 물리 값이 미확정이라는 사실은 별개다.

### 2.2 이차 탄성 공칭도 정적 평형이 크게 어긋난다

정착 S2/S1a/S1b의 마지막 3초 압력·각도를 사용해,
nominal의 정확한 `qdot=0` 평형을 다시 계산했다.

| 정착점 집합 | V_e=0 nominal 평형 RMSE | 이차 탄성 nominal 평형 RMSE |
| --- | ---: | ---: |
| S2 | 18.315° | 7.780° |
| S1a | 14.161° | 9.716° |
| S1b | 9.557° | 6.520° |
| 기존 84점 전체 | 16.076° | 8.047° |

이 값은 연속 궤적 RMSE와 다른 지표다. 그러나 장시간 정지 후에도 모델이 다른 각도로
가려는 이유를 드러낸다. 이차 탄성이 개발 궤적 RMSE를 줄였다는 이유만으로 실제
무압 탄성을 얻었다고 주장할 수 없다.

해당 탄성은 `V_e=k*q²/2+c*q`, k=1.7435 N m/rad, c=−1.4900 N m이다.
이 모델의 무압 평형은 18.41°, V_e=0 모델은 0°다.
로그의 대기압 근처 각도는 약 9–10°였다. 다만 텐던·정지 마찰이 있는 대기압 근처
관측을 독립적인 무마찰 탄성 평형 실험으로 간주할 수는 없다.
결론은 “탄성 함수가 실측으로 확정되지 않았다”이지, 그 차이만으로 올바른 탄성값을
역산해 확정할 수 있다는 뜻이 아니다.

### 2.3 기하를 피팅했다고 보기 어렵다

- meta에는 부하 2 kg, 링크 150 mm, 릴 반경 25 mm가 기록돼 있다.
  이는 실행 설정값이며 이번에 실제 치수를 재측정했다는 의미가 아니다.
- D=50 mm, L0=6 mm, n=14는 기존 지침에 따른 값이다. 실제 4번 개체 치수와
  챔버별 주름 수가 확인되지 않은 상태에서 임의로 바꾸지 않았다.
- x1_zero는 50 mm 최적화 하한에 걸렸고 x2_zero는 A2가 상수라 출력에 나타나지 않는다.
  x2_zero=84 mm를 측정·식별 완료 값으로 보고할 수 없다.
- 현재 x1_zero에서 q=0→73°의 A1은 약 1570.8→1518.7 mm²로 변화가 작다.
  q=50°, 음압 게이지 −30 kPa에서 기하가 만드는 진공 강성은 약
  **0.0248 N m/rad**인데 중력 강성은 **1.8917 N m/rad**다.
  현재 기하만으로 큰 정지 유지·압력 의존 특성이 자동 재현될 것이라 기대하기 어렵다.
- J=0.045 kg m²는 끝단 점질량 가정이고 별도 진자 식별값이 아니다.
  다만 현재 느린 데이터에서는 J가 주요 오차 원인이라는 근거도 약하다.

### 2.4 논문 문장과 실제 마찰식의 극한을 구분해야 한다

고정 epsilon>0에서 `qdot→0`이면 tanh 마찰도 0으로 간다.
따라서 논문의 “0에 가까운 속도에서 원 준정적 쿨롱식과 같아진다”는 문장을
그대로 정확한 정지에 적용하면 수학적으로 맞지 않는다.
포화 쿨롱 근사는 `|qdot|>>epsilon`인 조건 또는 극한 순서가 필요하다.
논문이 추가한 이력 상태가 정지 기억을 담당해야 한다. 논문 원문은 수정하지 않았다.

## 4. 물리 제약 및 수치 검증

- 저장 에너지의 압력 독립성, 스칼라 퍼텐셜의 미분, 양의 k/rho/rv,
  비음수 소산을 그대로 유지했다. 자유 힘 NN·자유 RNN·NN ReLU를 추가하지 않았다.
- 무작위 상태 4,000개: 수동성 위반 0, 전력 항등식 최대 오차 `8.88e-16 W`,
  에너지 수지 최대 오차 `2.84e-14 W`.
- 무입력 적분에서 저장 에너지 증가 없음.
- 개발 600초 전체: midpoint 50/10 ms 예측 차이 RMSE 0.00128°,
  midpoint 10 ms/독립 적응 적분 차이 0.000067°,
  적응 적분 허용오차 강화 차이 0.000918°.
- nominal·기준 residual·논문·모든 기존 원본 CSV/meta 해시 일치 확인.
- 테스트 83개 통과. 연속시간 수동성과 수치 회귀 검사를 실기 안전성이나
  이산 스텝별 정확한 수동성 보장으로 확대 해석하지 않는다.

## 5. 다음 판단

현재 결과를 최종 모델로 승격하지 않는다. **공칭 재식별의 목적과 물리 근거부터 정리해야 한다.**

1. 실제 부하·레버암·릴 반경, 챔버 기하·0° 길이를 사용자 실측과 대조한다.
2. S2 왕복을 같은 각도에서 짝지어 중심 토크와 이력 반폭을 분리하고,
   중심압별/S1a/S1b 기본 이득의 일관성을 확인한다.
   `nominal_diagnosis.json`에 같은 각도 보간의 탐색 진단을 남겼으며,
   이것을 독립 표본이나 실제 토크 측정으로 해석하지 않는다.
3. 실측 무압 탄성/기하 제약과 양립하는 nominal을 정한 후 residual을 다시 학습한다.
   정지 이력을 탄성이나 큰 마찰 계수에 억지로 흡수해 낮은 RMSE를 만들지 않는다.
4. 이후 필요한 경우 논문이 허용한 유효면적 보정과 이력 기저 확장을 별도 비교한다.
   현재 데이터만으로 효과를 완전히 분리할 수 없으므로 수동성뿐 아니라 물리적
   크기·독립 측정과의 일치도 확인한다.

물리 입력이 확인되지 않았다는 이유로 현재 데이터를 폐기할 필요는 없다.
다만 임의 치수 변경으로 NN·nominal 피팅을 진행하는 것은 이번 요구와 맞지 않는다.
사용자에게 실제 부하/레버암/릴 및 챔버 치수 확인을 요청했다.
