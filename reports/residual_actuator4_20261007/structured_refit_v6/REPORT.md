## 물리적 의미를 유지한 구현

`ph_model/structured_model.py`, `structured_model.cpp`에 별도 오프라인 모델을 구현했다.
기존 실기/압력 제어 코드는 호출하거나 수정하지 않았다.

### 1. 입력 포트: 양압·진공 유효면적

공칭의 `A_minus(x1)`, `A_plus` 식은 유지하고, 각각에 매끄러운 상대 면적 보정을 곱한다.
기저 입력은 챔버 길이와 압력 크기다. 기저는 상수, `tanh(z_x)`, `tanh(2z_x)`,
`tanh(|P|/50000)`이고, 출력 계수는 0에서 시작한다.
이는 고정된 매끄러운 tanh 뉴런에 선형 출력 계수를 피팅한 **작은 NN 기저 모델**이다.
다개체 공통 은닉 표현을 학습한 결과나 leave-one-actuator-out 검증은 아니다.

`A_i_eff = A_i_nominal * (1 + sum(c_ij * phi_ij))`

기저가 유계이므로 계수 절댓값 합을 제한해 모든 입력에서 유효면적이 양수가 되게 한다.
선정 모델의 면적 배율 전역 하한은 진공 약 0.446, 양압 약 0.430이다.
보정된 면적을 토크와 출력 포트 양쪽에 동일하게 사용한다:

`G = r * [-A_minus_eff, A_plus_eff]`, `tau_input = G @ P`, `y = G * qdot`.

따라서 `Pᵀy = tau_input*qdot`가 그대로 성립한다.
압력에 따른 형상 변화는 이 입력 포트에만 들어가며 **저장 에너지는 압력에 의존하지 않는다**.
학습 면적은 이 데이터와 고정 기하 아래의 유효 전달 계수이지 실제 단면적 실측값은 아니다.
모델의 출력 포트를 실제 챔버 유량 계측으로 검증한 것도 아니다.

### 2. 탄성: 스칼라 퍼텐셜

챔버 길이의 tanh 기저 4개로 `V_residual = sum(c_j*tanh(z_j(x2)))`를 정의한다.
힘은 이 스칼라 에너지의 미분이다. torch 자동미분과 고속 계산용 해석 미분의 일치를 테스트했다.
유계 기저이므로 모든 유한 계수에서 잔차 에너지는 아래로 유계다.
선정 잔차의 전역 하한은 약 −0.172 J다.

곡률의 거친 변화를 억제하는 정규화와 검사 영역의 음의 복원 강성에 대한 페널티를 넣었다.
이는 식별을 위한 명시적 사전조건이며 **수동성 정리 자체의 필수조건은 아니다**.
압력별 유효 강성 변화는 `d(V'−G(q,P)P)/dq`에서 생기며 압력 의존 탄성 에너지를 추가하지 않았다.

### 3. 소산: 음의 마찰·감쇠 금지

공칭 `alpha*|tau_nominal|*tanh(v/epsilon)+b*v`를 유지한다.
추가 마찰은 압력의 비음수 smooth basis와 비음수 계수로만 구성한다.
선정 후보의 추가 마찰 계수는 거의 0이므로 챔버별 추가 마찰을 강하게 식별했다고 주장하지 않는다.
추가 항으로 음의 소산이나 자유 힘 NN을 넣지 않았다.

### 4. 이력: 실제 저장 에너지가 있는 두 요소

`H_h = sum(0.5*k_j*(q-xi_j)^2)`

`xi_dot = (1/tau_j + rho_j*k_j*|v|)*(q-xi_j)` (k>0)

이는 논문의 `R_j = rv_j + rho_j*|v|`, `rv_j=1/(tau_j*k_j)`와 같다.
k=0인 초기 모델에서는 해당 요소의 힘/에너지를 0으로 두어 공칭과 정확히 일치시킨다.
계수는 모두 비음수이며 k는 위치·압력에 의존하지 않는 상수로 제한했다.
따라서 위치 의존 k의 에너지 미분을 빠뜨리는 문제도 없다.

선정값:

| 항 | 요소 1 | 요소 2 |
| --- | ---: | ---: |
| k [Nm/rad] | 0.003708 | 4.73788 |
| 정지 이완 시간 tau [s] | 1.351 | 599.983 |
| rho [1/Nm] | 39.6367 | 7.90014 |

두 번째 요소가 주된 이력 효과를 낸다. 속도 의존 미끄럼 항이 있으므로 위 tau를 운전 중
모든 상태의 시간상수로 해석하면 안 된다. **600 s는 탐색 상한이며 실제 물성으로 확정할 수 없다.**
후술한 시간상수 민감도에서도 긴 시간상수는 충분히 식별되지 않은 것으로 보인다.

## 검증

- 에너지 식은 압력에 무관, 잔차 퍼텐셜은 아래로 유계, 이력 저장 에너지는 비음수.
- 포트 일치 및 비음수 소산을 구조적으로 유지한다:
  `Hdot = P^T*y - v*tau_f - sum(R_j*f_j^2) <= P^T*y`.
- 선정 모델 무작위 5000 상태 검사: 부등식 위반 0, 전력 항등식 최대 오차 약 1.78e-15 W,
  에너지 균형 최대 오차 약 1.14e-13 W.
- 무입력 상태 적분에서 에너지 증가 없음.
- 독립 LSODA와 고속 5 ms 적분의 개발 각도 차이 RMSE 약 0.00147°.
- 20 ms와 5 ms 적분 차이 약 0.00302°로, 이번 개선량보다 훨씬 작음.
- 테스트: 105 passed. 무작위 검사만으로 정리를 증명하는 것이 아니라, 구조식과 구현을 대조하는 검사다.
- 연속시간 수동성은 수치 적분기의 엄밀한 이산시간 수동성 증명이 아니다.
