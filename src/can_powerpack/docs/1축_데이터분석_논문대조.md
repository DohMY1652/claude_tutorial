## 3. 논문 모델과의 대조

### 3-0. 왜 "논문 식을 최소자승으로 맞춘다" 가 안 되는가

평형식(Eq.28)은 θ 가 양변에 있는 **음함수**다.

```
sinθ = f̂₀(θ) + b̂ₚ·P_pos + b̂ᵥ·P_vac
```

여기서 `f̂₀(θ)` 를 자유 다항식으로 두고 최소자승을 돌리면 **다항식이 sinθ 를 그대로
흉내 내고 압력 항 계수가 0 으로 밀린다.** 실제로 해 보면 R²=0.9999, 각도 잔차
0.11° 가 나오는데 이건 성립의 증거가 아니라 **퇴화의 증거**다.

근본 원인: **압력이 0 인 상태에서 팔은 한 각도(5.9°)에만 있는다.** 그래서 정적
데이터만으로는 `f̂₀(θ)` 와 압력 항을 원리적으로 분리할 수 없다.

그래서 아래는 **`f̂₀` 를 몰라도 식별되는 양**만 다룬다. 핵심은 편미분의 비다:

```
(∂θ/∂P_pos) / (∂θ/∂P_vac) = b̂ₚ / b̂ᵥ          ← f̂₀ 가 소거된다
```

### 3-1. ★ 논문 Eq.32 의 "ΔP 하나로 뭉개기" 는 기각된다

논문은 실험 프로토콜상(챔버#1 을 −50 kPa 로 먼저 뺀 뒤 챔버#2 를 +60 까지 올림)
두 압력을 `P_diff = P_p − P_v` 하나로 축약했다. 우리는 두 챔버를 독립으로 몰았으므로
**같은 ΔP 를 다르게 배분해** 이 가정을 직접 시험할 수 있다 — 논문이 못 한 시험이다.

ΔP 를 고정하고 배분비 α = P_pos/ΔP 만 바꿨을 때:

| ΔP | α:0→1 일 때 각도 변화 | 상관 |
|---:|---:|---:|
| 20 | +2.32° | +0.34 |
| 30 | +2.82° | +0.45 |
| 40 | +4.78° | +0.58 |
| 50 | +7.59° | +0.65 |
| 55 | +9.93° | +0.70 |

ΔP 를 완전히 고정한 짝비교 (|ΔP 차|<0.6 kPa, |Δα|>0.2, 접근 방향 동일):

- 짝 **838 개 중 86.5 %** 에서 양압에 몰아준 쪽의 각도가 크다 (무관하면 50 %)
- 부호검정 **z = 21.1**, F검정 **p = 1.1×10⁻¹⁶**
- α 항을 넣으면 잔차가 4.03° → 3.21° 로 준다

**결론: 배분은 확실히 영향을 준다. ΔP 만으로는 각도를 결정할 수 없다.**
단 이것은 논문이 틀렸다기보다 **논문의 적용 범위**다 — 그 프로토콜에서는 α 가
ΔP 의 함수로 고정돼 있어 붕괴가 성립한다.

### 5-1. ★ 대기압 복귀 지점을 주기적으로 넣는다

### 5-2. ΔP 를 55 kPa 보다 올린다

## 6. 이 분석에서 내가 틀렸다가 고친 것

다음 사람이 같은 함정에 빠지지 않도록 남긴다.

1. **"드리프트 +12.6 °/시간"** — 반복 동작점의 시간차 vs 각도차를 회귀했더니
   나온 값. 틀렸다. 큰 시간차를 가진 짝이 하필 접근 방향이 다른 시나리오 사이에
   있어서 **이력을 드리프트로 읽은 것**이다. ΔP=0 점이 안 움직인 것으로 잡았다.
2. **논문 구조식 최소자승 (R²=0.9999)** — 퇴화였다. §3-0 참조. **R² 가 높다고
   좋아하지 말 것.** 평형식은 음함수다.
3. **"등각도 등고선이 가장 깨끗한 추정자"** — 틀렸다. 마찰 띠가 ±2° 라 "각도가
   같다" 가 "평형이 같다" 를 뜻하지 않는다. 이 추정자가 여기서는 제일 나쁘다.
4. **"효율비 1.46"** — 범위 비대칭(Pv 55 vs Pp 45)이 섞인 값이었다. 대칭으로
   자르면 1.30 이고, 그래야 논문과 비교할 수 있다.
