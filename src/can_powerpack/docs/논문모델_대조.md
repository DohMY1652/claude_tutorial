## 0. 용어 — 이 문서에서 쓰는 기호

| 기호 | 뜻 | 단위 |
|---|---|---|
| `P+`, `P−` | 양압 챔버 / 음압 챔버의 **절대압** | kPa abs |
| `u` | `P+ − 101.3` — 양압 챔버의 **게이지압** (대기압 위로 얼마나) | kPa |
| `v` | `101.3 − P−` — 음압 챔버의 **게이지압** (대기압 아래로 얼마나) | kPa |
| `ΔP` | `u + v` = `P+ − P−` — 차압 | kPa |
| `α` | 배분(allocation). `u = α·ΔP`, `v = (1−α)·ΔP` | — |
| `θ` | 관절 각도 (엔코더) | ° |
| `τ` | 액추에이터가 관절에 내는 토크 | N·m |
| `A` | **유효 면적**. 압력 1 kPa 당 얼마나 힘이 나오는가 | cm² |

`α = 1` 이면 양압만, `α = 0` 이면 음압만, `α = 0.5` 면 대칭이다.

## 1. 이 액추에이터가 무엇인가 (논문 2절, 그림 2)

일반 공압 실린더는 **옆면이 고정된 금속 통**이다. 그래서 유효 면적이 피스톤
단면적으로 고정이고, `F = A·P` 의 `A` 가 상수다.

이 액추에이터(**BiPAM**, Bidirectional Pneumatic Artificial Muscle)는 다르다.
논문 그림 2(a) 를 보면:

- **주름관(bellows)** 이 몸통이다. 얇은 알루미늄 막에 금속 와이어를 나선으로
  감았다. 세로로는 접히고 펴지지만 원주 방향으로는 안 줄어든다.
- 안에 **변형 가능한 천 구조(inner structure)** 가 있고, 그 중심을
  **건(tendon)** 이 관통해 힘을 밖으로 전달한다.
- 위아래를 **실링 캡**으로 막아 챔버를 만든다.

여기에 압력을 넣으면(**팽창, expansion**) 주름이 펴지면서 늘어나고, 빼면
(**수축, contraction**) 주름이 접히면서 줄어든다. **한 액추에이터가 양방향으로
힘을 낸다** — 그래서 "bidirectional" 이다. 논문 기준 수축률 75.1 %, 팽창률
402.3 % 다.

### 왜 면적이 상수가 아닌가

주름관이 **유연**해서다. 양압을 걸면 옆면이 부풀어 바깥으로 밀려나고, 음압을
걸면 오그라들어 안으로 빨려 들어간다. 즉 **압력을 거는 그 순간의 형상이 유효
면적을 바꾼다.** 그리고 길이(변위)가 바뀌면 주름이 접힌 정도가 바뀌므로 그것도
면적을 바꾼다.

이것이 이 문서 전체의 주제다: **`A` 가 무엇에 따라 어떻게 변하는가.**

### 그림 7 — 양·음압이 같이 힘을 내는 구조 (CoAM)

논문 3절, 그림 6~7 의 **CoAM**(Co-operative Antagonistic Mechanism)은
**DC-BiPAM**(Dual-Chamber BiPAM — 챔버 두 개를 중간판으로 나눈 것)을 쓴다.

```
   챔버 #1  ──┐
   (음압으로 뺀다 → 수축한다 → 당긴다)
              ├─ 중간판(움직이는 부분) ─ 건 ─ 도르래 ─ 관절
   챔버 #2  ──┘
   (양압으로 넣는다 → 팽창한다 → 민다)
```

**핵심은 두 챔버가 서로 맞서는 게 아니라 같은 방향으로 협력한다는 것이다.**
챔버 #1 을 빼고 챔버 #2 를 동시에 넣으면, 수축력과 팽창력이 **더해져서** 중간판을
같은 쪽으로 민다. 논문이 이 구조를 만든 이유이고(식 26), 전통적 길항 구조 대비
뭉친 토크 밀도가 2.58 배라고 보고한다 (표 4).

우리 장비가 바로 이 구조다. 그래서 `P+` 와 `P−` 를 **동시에** 지령한다.

## 2. 논문 모델 — 식을 하나씩

### 2-1. 출발점: 일 평형 (논문 2.5절, 식 4~5)

```
F·dL = −P·dV                              (식 4)
F(θ) = −P · (dV/dθ) / (dL/dθ)             (식 5)
```

**의미**: 액추에이터가 한 일 = 기체가 한 일. 힘은 "압력 × (부피가 변하는 속도 ÷
길이가 변하는 속도)" 다. 괄호 안의 양이 곧 **유효 면적**이고, 형상이 변하면
이것도 변한다. 실린더라면 이 값이 피스톤 면적으로 고정이다.

### 2-2. 수축(음압)일 때 (식 13~14)

논문은 주름관 부피를 원통에서 나선 삼각 단면이 지나간 자리를 뺀 것으로 모델링
하고(식 6~12), 미분해서:

```
F_con,model(θ) = −P · [ (nπD_i²/4)·(dL_u/dθ) − (dA/dθ)·l_arc − A·(dl_arc/dθ) ]
                 ───────────────────────────────────────────────────────────
                                        n·(dL_u/dθ)                     (식 14)
```

**의미**: 힘은 압력에 **비례**하지만, 비례상수가 주름의 접힌 각도 `θ`
(**주름 단면의 각도**이지 관절 각도가 아니다. 표 2 기준 50° → 0°)에 따라 변한다.
즉 **수축쪽은 유효 면적이 변위에 따라 달라진다.**

### 2-3. 팽창(양압)일 때 (식 15) — 여기가 중요하다

```
F_exp,model = P · πD_i²/4                 (식 15)
```

**의미**: 압력을 넣으면 접혀 있던 주름이 밖으로 밀려나 **원통 모양이 된다**
(논문 그림 3(d)). 원통이 되고 나면 단면이 그냥 원이므로 `dV/dL = πD_i²/4` 로
고정이다. 논문 표현 그대로:

> "Eq. (15) shows that the force generated when pressing down on an actuator is
> proportional to the internal pressure, **regardless of how the actuator's
> geometry changes**."

즉 **팽창쪽 유효 면적은 상수**라는 것이 논문의 주장이다.

표 2 의 `D_i = 54.5 mm` 를 넣으면 `π·54.5²/4 = 2333 mm² = 23.3 cm²` 다.

### 2-4. 실측으로 맞춘 다항식 (식 16~17, 표 3)

논문은 위 이론식 대신 **blocked-force 실험**(그림 4: 액추에이터 길이를 25~125 mm
로 고정해 놓고 로드셀로 힘을 잼)에서 MATLAB 으로 맞춘 다항식을 실제로 쓴다:

```
F_con = c00 + c10·x_con + c01·P_vac + c11·x_con·P_vac + c20·x_con²      (식 16)
F_exp = e00 + e10·x_exp + e01·P_pos                                     (식 17)
```

**표 3 의 계수** (힘 N, 변위 mm, 압력 kPa):

| | | | |
|---|---:|---|---:|
| `c00` | 6.372 | `e00` | −0.8884 |
| `c10` | −0.2148 | `e10` | 0.01138 |
| `c01` | −1.517 | `e01` | 2.077 |
| `c11` | −0.001426 | | |
| `c20` | 0.00656 | | |

여기서 **유효 면적을 읽어낸다.** 유효 면적이란 "압력이 1 kPa 오르면 힘이 몇 N
늘어나는가" 이므로, 압력에 대한 편미분이다:

```
팽창:  ∂F_exp/∂P_pos = e01 = 2.077 N/kPa
       → 2.077 N/kPa = 2.077×10⁻³ N/Pa = 2077 mm² = 20.8 cm²
       x_exp 항(e10)이 없으므로 **변위와 무관**, P 항이 1차뿐이므로 **압력과도 무관**

수축:  |∂F_con/∂P_vac| = |c01 + c11·x_con| = 1.517 + 0.001426·x_con N/kPa
       → x=20 mm  : 15.5 cm²
         x=60 mm  : 16.0 cm²
         x=99 mm  : 16.6 cm²
       **변위에 따라 커진다(전 행정 +9.4 %). 압력과는 무관.**
```

이론값 23.3 cm² 와 실측 20.8 cm² 가 11 % 차이인데, 논문도 그 정도로 본다.

> **여기서 나오는 두 가지 검증 가능한 주장**
> 1. **양압쪽 면적이 음압쪽보다 크다.** `20.8 / 15.5~16.6` = **1.25 ~ 1.34 배**
> 2. **면적은 압력과 무관하고, 변위에만 약하게(+9 %) 의존한다.**

### 2-5. 두 챔버가 더해진다 (식 29)

```
F_act = F_1 + F_2 = F_con(P_v, x_1) + F_exp(P_p, x_2)                   (식 29)
```

**의미**: 그림 7 구조에서 수축 챔버가 당기는 힘과 팽창 챔버가 미는 힘이 **단순히
더해진다.** 서로 간섭하는 항(예: `P_v·P_p` 같은 교차항)이 **없다.** 이것도
검증 가능한 주장이다.

### 2-6. 변위와 관절 각도의 관계 (식 30~31)

```
x_sum = x_1 + x_2                                                       (식 30)
x_2   = r_e·θ + x_i                                                     (식 31)
```

**의미**: 건이 닫힌 고리라서 **두 챔버 변위의 합이 항상 일정**하다 (한쪽이
늘면 다른 쪽이 정확히 그만큼 준다). 그리고 팽창 챔버의 변위는 관절 각도에
비례한다 — 도르래에 감기니까.

표 5 기준 `r_e = 38.6 mm`, `x_i = 20 mm`, `x_sum = 120 mm`.
관절 0°→117° 에서 `x_2` 는 20→99 mm, `x_1` 은 100→21 mm 로 움직인다.

**이 식 덕분에 각도만 알면 두 챔버의 변위를 모두 안다.** 우리 대조에서도 이걸
그대로 쓴다.

### 2-7. 배분 규칙 (식 32) — 논문에 **없는 자유도**

```
F_act = F_con(P_diff, x_1)                        if P_diff ≤ k
      = F_con(k, f(θ)) + F_exp(P_diff − k, x_2)   otherwise              (식 32)
   where P_diff = P_p − P_v ,  k = |P_v,min| = 50 kPa
```

**의미**: 논문은 차압 `P_diff` 하나만 제어 변수로 두고, **음압을 먼저 −50 kPa
까지 다 쓰고, 그 다음에 양압을 더한다**는 **고정 순서**를 따른다.

> **중요**: 논문은 **같은 차압에서 배분을 바꿔 보지 않았다.** 그래서 논문 모델은
> 배분을 표현할 방법이 없다. 우리 시나리오 5·10 이 정확히 그 빈칸을 찌른다.

### 2-8. 마찰 (식 33)

```
f_t = f_t1 + f_t2
    = (1 − e^{μ(θ1+θ2)})·F_act + (1 − e^{μ(θ3+θ4)})·F_act
    = (α_1,2 + α_3,4)·F_act                                              (식 33)
```

**의미**: 건이 베어링 4개를 감고 지나가므로 **캡스턴(capstan) 마찰**이 생긴다.
로프를 기둥에 감으면 장력이 지수적으로 줄어드는 그 현상이다. 핵심은 이것이
**액추에이터 힘에 비례**한다는 점이다 — 일정한 마찰이 아니다.

표 5: `α_1,2 = 6.8×10⁻²`, `α_3,4 = 6.6×10⁻²` → 합 **0.134**, 즉 **액추에이터
힘의 13.4 %**.

> **세 번째 검증 가능한 주장**: 마찰은 힘에 비례하고 그 비가 13.4 % 다.

### 2-9. 관절에서의 토크 평형 (식 27~28, 35~36)

```
ΣT_O = T_act − T_w − T_load = 0                                          (식 27)
T_act    = r_e·(F_act(P_diff, θ) − f_t)                                  (식 35)
T_passive = r_cm·W + R_arm·F_load·sin θ                                  (식 36)
```

**의미**: 팔이 멈춰 있으면 액추에이터 토크와 중력 토크가 같다. 그래서
**각도 하나를 재면 토크를 역산할 수 있다.** 이것이 우리 측정의 원리이기도 하다.

표 5 의 기구 상수: `r_e = 38.6 mm`(관절–건 반지름), `R_arm = 300 mm`(팔 길이),
`r_cm·W = 0.360 N·m`(팔 자중 토크, 90° 에서 실측).

## 3. 우리가 잰 것

`scripts/pressure_id_seq.py` 로 1축에 압력 레퍼런스를 주고, 각 목표에서
**5초 유지 → 뒤쪽 40 % 를 평균**해서 한 점으로 만들었다. 쓴 시나리오:

| | 무엇 | 왜 쓰나 |
|---|---|---|
| 1 | `P+` × `P−` 격자 (ΔP ≤ 55) | (P+, P−) 평면을 넓게 덮는다 |
| 3 | 양압만 사다리 (`P− = 대기압`) | **`v = 0` 이라 양압 챔버만 따로 본다** |
| 4 | 음압만 사다리 (`P+ = 대기압`) | **`u = 0` 이라 음압 챔버만 따로 본다** |
| 5 | 등차압 배분 (ΔP 고정, α 변경) | **논문에 없는 배분 자유도를 찌른다** |

걸러낸 뒤 **정적 점 132개**가 남았다 (유지 중 각도 σ < 0.3°, `u` 0~55 kPa,
`v` 0~61 kPa, 각도 10~71°).

각 점에서 토크를 역산한다 — 논문 식 27 과 같은 원리다:

```
τ = m·g·L·sin(θ)          m·g·L = 2.943 N·m 을 **가정**했다 (뒤에서 다시 본다)
```

**3·4번이 특히 중요하다.** 한 챔버만 쓰므로 `F_con` 과 `F_exp` 를 **서로 섞이지
않게** 따로 볼 수 있다. 논문의 blocked-force 실험(그림 4)과 같은 역할이다.

### 마찰을 어떻게 다루나

이 액추에이터는 **올라오다 멈춘 자리**와 **내려오다 멈춘 자리**가 다르다
(히스테리시스). 같은 압력인데 각도가 다르다. 그래서 매 점마다 **직전 점보다
올라왔는지 내려왔는지**를 `s = ±1` 로 기록하고, 모델에 마찰항을 따로 넣는다.

실측한 이력 폭:

| 게이지압 | 양압만(3번) 올림↔내림 | 음압만(4번) 올림↔내림 |
|---:|---:|---:|
| 10 kPa | 5.30° | 2.90° |
| 20 kPa | 9.22° | 4.34° |
| 30 kPa | 14.65° | 5.19° |

**양압쪽 이력이 음압쪽의 2.5배**이고, 둘 다 압력이 커질수록 넓어진다.
→ 식 33 의 "마찰 ∝ 힘" 과 정확히 같은 경향이다 (양압쪽이 힘이 더 크니까).

## 4. 대조 — 논문 구조를 우리 데이터에 맞춰 본다

논문의 **구조**(어떤 항이 있고 없는지)만 가져와 계수는 우리 데이터로 다시
맞춘다. 그리고 5-겹 교차검증으로 **보지 않은 점을 얼마나 잘 맞히는지** 잰다.
오차는 토크 잔차를 그 각도에서의 각도 오차로 환산한 값이다.

| 모델 | 무엇이 들어 있나 | 항 | 검증 오차 |
|---|---|---:|---:|
| **P1** | **논문 그대로.** 두 면적이 상수, 마찰 ∝ 힘 | 3 | **4.86°** |
| P2 | P1 + 수축 면적이 변위에 (식 16 의 `c11`) | 4 | 4.66° |
| P3 | P2 + 팽창 면적도 변위에 | 5 | 3.86° |
| E1 | 우리 것 — 면적이 **자기 압력**에 | 6 | 3.44° |
| E2 | E1 + 교차항 `u·v` | 7 | **2.39°** |

**P1 이 파라미터 3개로 4.86° 다.** 위에서 본 마찰 밴드가 ±3~6° 이므로, 논문
모델은 **이 액추에이터의 본질적 불확실성과 같은 크기**로 맞는다. 더 복잡한
모델을 써도 2.39° 까지밖에 안 내려간다.

## 5. 항목별로 — 무엇이 맞나

### ✅ 5-1. 두 챔버가 더해진다 (식 29)

교차항 없는 3항 모델(P1)이 4.86° 면 가법성 자체는 문제가 없다. 그림 7 의 협력
구조가 데이터에 그대로 보인다.

### ✅ 5-2. 양압쪽이 음압쪽보다 세다

```
우리  A_p/A_n = 1.16          논문 = 1.25 ~ 1.34
```

**이 비교에는 가정이 하나도 안 들어간다.** `m·g·L` 도 `r_e` 도 분자·분모에서
약분되기 때문이다. 그래서 이 항목이 가장 믿을 만한 대조다. 방향이 같고 크기가
11 % 차이다.

물리적으로도 말이 된다 — 양압에서는 주름이 펴져 원통이 되니 면적이 크고
(논문 그림 3(d)), 음압에서는 오그라들어 작다.

### ✅ 5-3. 수축쪽 면적이 변위에 따라 커진다

논문 `c11` 의 부호가 "`x_con` 이 클수록 `|∂F/∂P|` 가 크다" 를 말한다.
우리 P2 적합의 해당 계수도 **같은 부호**다. (크기는 다르다 — 6절)

### ✅ 5-4. 마찰이 액추에이터 힘에 비례한다 (식 33)

```
우리  마찰 / 액추에이터 힘 = 8.8 %        논문 = 13.4 %
```

구조(비례)도 크기(같은 자릿수)도 맞는다. 그리고 3절 표의 "양압쪽 이력이 2.5배"
가 이 식으로 자연스럽게 설명된다 — 마찰이 절대량이 아니라 힘의 비율이므로,
힘이 큰 쪽에서 이력이 넓어진다. **우리가 데이터에서 먼저 보고 의아해했던 현상이
논문 식 33 에 이미 들어 있었다.**

### ✅ 5-5. 절대 크기도 모순되지 않는다

`r_e = 38.6 mm`(표 5)로 환산하면:

| | 우리 | 논문 |
|---|---:|---:|
| `A_p` | 15.3 cm² | 20.8 cm² |
| `A_n` | 13.2 cm² | 16.0 cm² |

둘 다 우리가 ~25 % 작다. **그런데 이 값들은 `τ = m·g·L·sin θ` 의 `m·g·L` 에
그대로 비례한다.** 우리는 그 값을 모르고 `actuator_map.py` 기본값 2.943 N·m 를
가정했을 뿐이다.

두 면적을 동시에 맞추는 축척을 풀면 **1.297** 이 나오고, 그러면:

```
실제 중력상수 = 2.943 × 1.297 = 3.82 N·m
   → 논문 팔(R_arm 0.3 m, r_cm·W 0.36 N·m)이라면 payload 약 1.2 kg
   → 그 축척에서 우리 A_p 19.8 / A_n 17.1 cm²  (논문 20.8 / 16.0)
```

**1.2 kg 은 물리적으로 전혀 이상하지 않은 값이다** (논문 데모는 0·1·2 kg 로
실험했다). 즉 절대 크기의 차이는 모델 불일치가 아니라 **우리가 기구 상수를
모르는 것**으로 충분히 설명된다.

> 실제 payload·모멘트암·`r_e` 를 알려주면 이 항목은 확정할 수 있다.
> `--mass / --link / --reel-dia` 로 넣으면 된다.

## 6. 갈리는 곳 — 변위 의존성의 **크기**

```
수축 면적이 변위 x1 이 0 → 100 mm 로 갈 때

   논문 (c11/c01)   +9.4 %
   우리 (P2 적합)   +188.8 %      ← 부호는 같은데 크기가 20배
```

그리고 논문은 면적이 **압력과 무관**하다고 하는데(식 15), 우리 데이터는 압력
의존을 원한다 (E1 이 P1 보다 1.4° 낫다).

### 그런데 이건 논문이 틀렸다는 증거가 못 된다

**정적 측정의 근본적 한계 때문이다.** 팔은 항상 **그 차압의 평형 각도**에
앉는다. 차압을 올리면 각도도 따라 올라간다. 즉

```
압력 ↑  ⟹  각도 ↑  ⟹  변위 ↑
```

세 가지가 한 덩어리로 움직인다. **"면적이 압력 때문에 변한다" 와 "면적이 변위
때문에 변한다" 를 이 데이터로는 구별할 수 없다.**

실제로 표를 보면:

```
P3 (변위 탓으로 설명)   3.86°
E1 (압력 탓으로 설명)   3.44°
```

**거의 비등하다.** 논문의 물리(형상 변형이 원인)가 맞고, 제가 "압력 탓"으로
붙인 것이 오귀인일 가능성이 충분하다. 두 설명이 이 데이터에서 관측적으로
동등하다.

## 7. 논문 모델에 아예 없는 것 — 배분

2-7절에서 본 대로 논문은 **차압 하나**를 제어 변수로 쓰고 배분은 고정 규칙이다.
우리 시나리오 5 는 **차압을 고정하고 배분만** 바꿔 봤다:

| ΔP = 50 kPa 고정 | 각도 |
|---|---:|
| α = 0 (음압만) | 60.30° |
| α = 0.25 | 59.19° |
| α = 0.50 | 59.29° |
| α = 0.75 | 60.69° |
| α = 1 (양압만) | 64.51° |

**같은 차압인데 각도가 5.3° 움직인다.** `F = A·ΔP` 에 `A` 가 상수라면 0 이어야
하는 값이다. 논문 모델은 이 자유도를 표현할 식이 없다 — 실험을 안 했으니 당연
하다.

우리 E2 의 교차항 `u·v` 가 이걸 담는다 (3.44 → 2.39°). 다만 논문 구조에 교차항만
얹으면 개선이 없어서, 이 효과는 면적–압력 항과 엉켜 있다. **더 파려면 8절의
실험이 필요하다.**

## 8. 그래서 다음에 무엇을 해야 하나

### 8-1. 각도 고정 시험 (locked-rotor) — 가장 값어치 있다

6절의 교란을 푸는 유일한 방법이다. **팔을 한 각도에 붙들어 놓고 압력만 훑는다.**
그러면 변위가 상수이므로, 면적이 변하면 그건 **압력 탓**이다.

방법: `angle_ctrl.py` 로 각도를 잡아 두고 시나리오 5·10 처럼 배분만 돌린다.
(이 브랜치 `DMY_actuator_variance` 에서는 `angle_ctrl.py` 를 안 쓰기로 했으므로,
개체차 측정이 끝난 뒤의 작업이다.)

이 시험 하나로 판정되는 것:
- 논문 식 15 의 "팽창 면적은 압력과 무관" — 참/거짓
- 7절의 배분 효과가 면적–압력 때문인지, 두 챔버의 기하학적 간섭 때문인지

### 8-2. 기구 상수 확정

`m·g·L` 과 `r_e` 를 알면 5-5절이 확정된다. 지금은 `actuator_map.py` 기본값
(`--mass 2.0 --link 0.15 --reel-dia 0.05`)을 쓰고 있는데, 논문 기구
(`r_e = 38.6 mm`, `R_arm = 300 mm`)라면 맞지 않는 값이다.

### 8-3. 동특성

지금 대조는 **전부 정적**이다. 논문 2.7절의 동적 응답(상승 시간 수축 1.25 s / 팽창 0.85 s,
대역폭 −3 dB 약 2.1 Hz)과 대조하려면 `pressure_id_seq.py` 의 시나리오 6~10
(큰 계단 · 작은 계단 · APRBS)이 필요하다. 아직 못 받았다.

### 8-4. 다른 축

지금 대조는 1축 하나다. 개체차 측정이 끝나면 6축 전부에 같은 적합을 돌려
**어느 계수가 축마다 다른지**를 보면, 개체차가 "면적 차이" 인지 "마찰 차이"
인지가 갈린다. 이 브랜치의 원래 목표와 바로 이어진다.

## 9. 한 줄 요약

> 논문의 3-파라미터 모델이 우리 132개 정적 측정을 **4.86°** 로 맞춘다.
> 마찰 밴드가 ±3~6° 인 액추에이터에서 이건 **잡음 안에서 맞는 것**이다.
> 가법성 · 챔버 비대칭 방향 · 변위 의존 부호 · 마찰의 힘 비례 구조 · 면적
> 절대크기 — **다섯 항목 모두 논문과 같은 방향이고 같은 자릿수**다.
> 갈리는 것은 변위 의존의 *크기* 하나인데, 그것은 정적 실험에서 각도와 압력이
> 얽혀 있어 **우리 데이터로 판정이 불가능**하다.
