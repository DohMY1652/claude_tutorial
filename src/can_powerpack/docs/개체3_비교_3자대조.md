## 3. 3번의 b = 1.30 — 눈금은 아니다 (확인 완료)

처음에는 눈금 오차를 의심했다. **두 보정점을 물리 자세에서 실측해 확정했고,
눈금은 문제가 아니었다.**

| 단계 | raw@0 | raw@90 | counts/deg | 3번 vs 1번 b |
|---|---:|---:|---:|---:|
| 최초 (오측) | 29300 | 4600 | 274.4 | — |
| 2차 (오측) | 30700 | 11000 | 218.9 | 1.321 |
| **실측 확정** | **29000** | **9000** | **222.2** | **1.301** |

확정 보정의 222.2 counts/deg 는 1번(218.4)·2번(225.1) **사이**에 정확히 들어온다.
그런데 **b 는 1.321 → 1.301 로 거의 안 움직였다** — 환산의 배율 성분이 0.985 뿐이고
나머지는 오프셋(−7.65°)이었기 때문이다.

> **따라서 30 % 기울기 차이는 실제 개체차다.** 부트스트랩 97 % 가 모형 B(각도 배율)를
> 지지하므로, 힘(압력당 출력)이 아니라 **기구 형상** 쪽 차이로 읽힌다 —
> 논문 Eq.31 `x₂ = r_e·θ + x_i` 와 Eq.35 `T_act = r_e·(F_act − f_t)` 의 유효 반경
> `r_e`, 또는 풀리·건 경로다. 효율비(두 챔버의 면적비)는 셋 다 같으므로
> 챔버 자체의 문제는 아니다.

### 교란 요인은 전부 지웠다

- **압력 불일치 아니다.** 공통점에서 3번의 실측 Pp 가 오히려 2.44 kPa 낮다
  (레일이 약했다) — 관측 방향과 반대다.
- **외삽 아니다.** 공통 u 범위 안에서만 비교했다.
- **눈금 아니다.** 위 실측으로 확정.

### 남은 의문

3번의 휴지 각도가 **처녀 −3.18° / 길든 뒤 +4.07°** 로 셋 중 가장 낮다 (1번 6.98,
2번 9.68). 음수는 0° 기준 자세보다 팔이 더 내려가 쉰다는 뜻이다. 0° 보정 자세가
정확히 수직이었는지 한 번 더 볼 가치가 있다 — 다만 **기울기 b 는 영점과 무관**하므로
위 결론은 바뀌지 않는다.

## 4. 어제 분석에서 고칠 것

**"1·2번 차이는 전 구간 일정한 오프셋 +3.4°" 는 틀렸다.**

양쪽 다 3회 이상 방문한 24 개 공통점만 보면 차이가 u 에 따라 **자란다**:

```
차이 = +1.51 + 0.0975·u      상관 +0.703
   u=10 에서 +2.5°,  u=45 에서 +5.9°
```

일정 오프셋으로 보면 잔차 sd 1.60°, 기울기를 넣으면 1.14° 다. 어제는 MAD 이상치
제거가 **고-u 점들을 잘라내 기울기를 없앴다.** 곡선 기반 부트스트랩도 압력 이득
k = 1.085 (85 %) 를 지지한다 — **2번은 1번보다 8.5 % 센 개체**이지 영점만 다른 게
아니다.

실용 결론은 그대로다: 오프셋 상수 하나로 RMSE 5.16 → 2.74 (바닥 2.68) 이라
**남은 이득 성분은 마찰 바닥에 묻힌다.** 기전 설명만 틀렸다.
